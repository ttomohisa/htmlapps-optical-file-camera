# Optical File

Optical File（QR Tape）は、小さなファイルを**連続QRのAnimated WebP**へ変換し、別端末に表示したAnimated QRをカメラで読み取るか、そのWebPを直接解析して元ファイルをブラウザー内だけで復元するツールです。

- アップロードなし / 実行時ネットワーク通信なし
- 出力はAnimated WebP（`.webp`）
- カメラ優先モード: 1フレームに1 QR
- 速度優先モード: 1フレームに4 QR
- データブロックごとにCRC32、復元ファイル全体をSHA-256で検証
- 効果がある場合はQR化前にgzip圧縮
- 日本語 / 英語UI
- テンプレートの単一HTML・自己解凍HTMLビルドに対応

## 想定サイズ

入力上限は**1 MiB**です。画面越しのカメラ読み取りを優先し、1 QRあたりの情報量を抑えています。ファイルが大きいほどQRフレーム数とWebPサイズは増えます。

## ビルド

Windowsで以下を実行します。

```bat
build-standalone.bat
```

固定したnpm依存を単一HTMLへ内包します。

## 復元対応

WebPファイルを直接復元するときはブラウザーの`ImageDecoder` APIを利用します。カメラ復元は`getUserMedia()`を使い、別端末のAnimated QRを画面越しに読み取ります。カメラ利用にはブラウザーの許可が必要です。

## セキュリティ / プライバシー

処理はすべてローカルです。生成したWebPには元ファイルのデータが含まれ、**暗号化はしていません**。WebPを持っている人は元ファイルを復元できます。

詳細は [SECURITY.md](SECURITY.md)、[APP_SPEC.md](APP_SPEC.md)、[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。


## カメラ読み取り

画面撮影時の白飛びを抑えるため、低輝度グレーのQR背景を使用し、既定を1 QR/frameにしています。対応端末ではカメラ露出も自動で下げます。

## メタデータ待ちの短縮

メタデータQRはコンパクトなBase45形式で、Animated WebPの途中にも約2秒ごとに再挿入します。カメラが先にデータQRを読んだ場合もCRC32検証済みブロックを仮保存し、後からメタデータを取得した時点で自動的に統合します。
